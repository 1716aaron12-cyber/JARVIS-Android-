# JARVIS Android

Native Android app with cinematic UI, Android speech recognition, UK English text-to-speech, settings and browser shortcuts.

## Build APK using GitHub Actions
Upload project contents to a GitHub repository, open Actions > Build JARVIS APK > Run workflow. Download the JARVIS-APK artifact from the successful run, unzip it and install app-debug.apk.

Note: This is an MVP, not a full AI assistant. Voice quality depends on installed Android TTS voices; ElevenLabs is not integrated. No secret keys are required. This debug APK is for personal testing.
